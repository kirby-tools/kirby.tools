**🚀 Features**

- **Dynamic API key resolution**: The `apiKey` option now accepts a closure, so the key can depend on the current user or other context at runtime. See the [Global Configuration documentation](/docs/copilot/configuration/global#dynamic-api-keys).
- **Localized prompt templates**: Default prompt templates are now available in English, German, French, and Dutch. Templates are automatically selected based on the Panel user's language setting.
