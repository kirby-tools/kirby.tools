**🚀 Features**

- **Page references**: Reference other Kirby pages in your prompt with `@page://page-id` to include their content as context for the AI. Insert pages via the toolbar dropdown or type the syntax manually. See the [page references documentation](/docs/copilot/prompt-dialog/page-references) for details.
- **Syntax highlighting**: The prompt editor now highlights `{placeholder}` tokens and `@page://` references with distinct colors for better readability.

**🐞 Bug Fixes**

- **Custom field types no longer block generation**: A custom field type that extends a standard one, such as `'extends' => 'text'`, stopped generation with an "Unsupported field type" error. Copilot now generates content for it, and skips a field type it cannot fill instead of failing. ([#8](https://github.com/kirby-tools/kirby-copilot/issues/8))
