**🚀 Features**

- **Block descriptions**: Custom block blueprints now support an optional `description` key that is passed to the AI schema, giving the model richer context about each block's purpose. See the [Blocks & Layouts documentation](/docs/copilot/advanced/blocks-and-layouts#block-descriptions).
- **Nested blocks support**: A custom block with its own `type: blocks` field – blocks within blocks – now gets content for its nested blocks too, one level deep. See the [Blocks & Layouts documentation](/docs/copilot/advanced/blocks-and-layouts#nested-blocks).
