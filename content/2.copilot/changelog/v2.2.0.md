**🚀 Features**

- **Anthropic image input**: Enable image input for prompts when using an **Anthropic** model.
- **Per-site prompt history**: Prompt history is stored per hostname in the browser's local storage.
- **API error handling**: Pass all API errors to the Panel user interface for better error handling.
