**🚀 Features**

- **PDF context support**: Add PDF files as context for AI prompts. Text content is extracted from each PDF and appended to the prompt, enabling AI generation based on document content. Configure PDF files using the [`files`](/docs/copilot/usage/section#files) section property.

**🐞 Bug Fixes**

- **Hosting compatibility**: Some hosts serve `.mjs` files with the wrong MIME type, so the browser refused to load Copilot's AI library and generation failed. The plugin now ships its scripts as `.js`.
