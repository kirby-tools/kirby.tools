::tip
This release teaches [Agents](/docs/copilot/agents), Copilot's MCP server, to edit inside a field: one sentence, one block – the rest stays as it was.
::

**🚀 Features**

- **Edits inside a field**: An agent now rewrites a single passage instead of the whole field – in a blocks or layout field, only inside the block that holds it. It also adds, moves, or removes single blocks and leaves the others untouched. See [Tools](/docs/copilot/agents/tools).
- **Finding open work**: Agents now find the pages and files not yet translated into a language, and search files across the site, such as images without alt text. An agent that starts a new translation also learns which fields still hold the default language's text.
- **Before publishing**: An agent can now tell you what publishing a page would change. When it writes to a page that holds unsaved changes a colleague left, it tells you that too, since the Panel then shows them as yours. See [Working Alongside an Agent](/docs/copilot/agents/permissions-and-review#working-alongside-an-agent).

**🐞 Bug Fixes**

- **Values a field doesn't take**: A write that Kirby would empty or cut short, such as an option a select doesn't have or a block type a field doesn't offer, is now refused, and the agent learns what the field takes. Before, the field ended up empty or held a block the site doesn't show.
