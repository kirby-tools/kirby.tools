::tip
This release is all about [Agents](/docs/copilot/agents), Copilot's MCP server. An agent now edits inside a field: one sentence, one block – the rest stays as it was.
::

**🚀 Features**

- **Edits inside a field**: Ask for a sharper paragraph, and the agent replaces just that passage – in a blocks or layout field, inside the one block that holds it. It adds, moves, or removes single blocks the same way, and the other blocks stay untouched. See [Tools](/docs/copilot/agents/tools).
- **Finding the work**: Agents find the pages and files not yet translated into a language, and search the files of the whole site, such as the images without alt text. When an agent starts a translation, it learns which fields still hold the default language's text.
- **Before you publish**: Asked what publishing would change, an agent compares a page's unsaved changes with its published version. When it writes to a page that holds a colleague's leftover unsaved changes, it tells you, so you review both before publishing. See [Working Alongside an Agent](/docs/copilot/agents/permissions-and-review#working-alongside-an-agent).
- **Deleting as in the Panel**: An agent with Delete content can now delete a page or file that has unsaved changes, as you can in the Panel – unless a colleague is editing it right now. See [Delete Content](/docs/copilot/agents/permissions-and-review#delete-content).

**🐞 Bug Fixes**

- **Values a field doesn't take**: A write Kirby would empty or cut short, such as an option a select doesn't have or a block type a field doesn't offer, is now refused, and the agent gets the field's options to try again. Before, Kirby stored an empty field or a block the site doesn't show.
- **Writer paragraphs**: Plain text an agent writes into a writer field lands in a paragraph, as when you type it in the Panel.
