**🚀 Features**

- **Reasoning effort support**: Support [`reasoningEffort`](/docs/copilot/configuration/global#reasoningeffort) for OpenAI GPT-5 and GPT-5 Mini, replacing `temperature` for these models.
- **Customizable view button props**: Configure the Copilot view button in your blueprints, overriding the global defaults. Set its [`label`](/docs/copilot/configuration/local#label), [`theme`](/docs/copilot/configuration/local#theme), and [`logLevel`](/docs/copilot/configuration/local#loglevel), pre-fill the dialog with a [`userPrompt`](/docs/copilot/configuration/local#userprompt), or steer the output with a [`systemPrompt`](/docs/copilot/configuration/local#systemprompt) that editors never see.

For example, the view button with `theme: blue-icon`:
