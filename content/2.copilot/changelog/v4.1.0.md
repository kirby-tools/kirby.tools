**🚀 Features**

- **File tags in the prompt dialog**: Files you attach show as tags below the prompt, as they do in the Copilot field. You can remove them one by one. See [File Attachments](/docs/copilot/prompt-dialog/files).
- **Thumbnails on file tags**: A tag shows a thumbnail of its image, or a document icon for a PDF.

**🐞 Bug Fixes**

- **Blocks fields with Anthropic**: The [view button](/docs/copilot/usage/view-button) no longer fails with an Anthropic model when a blocks field is among the selected fields.
- **Mistral error messages**: When Mistral rejects a request, for an unknown model or an invalid API key, Copilot shows Mistral's message instead of a PHP error.
