**🚀 Features**

- **Request timeout for PHP runs**: A new per-provider [`timeout`](/docs/copilot/configuration/global#timeout) option bounds every request the [`Client`](/docs/copilot/php-classes/client) class makes, defaulting to 120 seconds. A stalled connection used to block the script indefinitely.

**🐞 Bug Fixes**

- **Bounded retry delay**: The OpenAI-family providers cap a `Retry-After` hint at one minute and read its HTTP-date form, instead of sleeping for however long the provider asked. See the [OpenAI provider reference](/docs/copilot/php-classes/providers/openai).
- **Structured responses without content**: An OpenAI-family response with no message content throws a `ProviderException` instead of a `TypeError`.
