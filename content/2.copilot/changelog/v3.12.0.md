**🚀 Features**

- **Request timeout for PHP runs**: A new per-provider [`timeout`](/docs/copilot/configuration/global#timeout) option bounds every request the [`Client`](/docs/copilot/php-classes/client) class makes, defaulting to 120 seconds. A stalled connection used to block the script indefinitely.

**🐞 Bug Fixes**

- **Bounded retry delay**: When an OpenAI-family provider asks for a pause with `Retry-After`, the retry now waits at most one minute instead of however long it asked. See the [OpenAI provider reference](/docs/copilot/php-classes/providers/openai).
- **Structured responses without content**: An OpenAI-family response with no content made `Client::generateObject()` fail with an error that slipped past a `ProviderException` handler. It now throws a `ProviderException`, like any other provider failure.
