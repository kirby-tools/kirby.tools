**🚀 Features**

- **Config validation for skills and prompt templates**: With Kirby's `debug` option on, a malformed [`skills`](/docs/copilot/configuration/global#skills) or [`promptTemplates`](/docs/copilot/configuration/global#prompttemplates) entry – and two skills sharing an `id` – now raise an `InvalidArgumentException` that names the offending entry by its config key. With debug off, only that entry is skipped and the rest of the list is kept. See the [exceptions reference](/docs/copilot/php-classes/exceptions).

**🐞 Bug Fixes**

- **Skills in programmatic prompts**: Skill mentions resolve in every generation run, including prompts sent through the plugin API. They previously depended on the prompt dialog having been opened first, so a programmatic run lost its instructions without a trace. See the [skills documentation](/docs/copilot/prompt-dialog/skills).
- **Mentions inside words**: `@skill://` and `@page://` mentions are recognized only at a word boundary, so `see@page://about` stays plain text. Punctuation around a mention is still fine – `"@page://about"` resolves.
- **Unresolved mentions**: An unknown skill ID or an unreadable [page reference](/docs/copilot/prompt-dialog/page-references) is still skipped, but now names itself in a browser console warning instead of vanishing silently.
- **Page picker at the cursor**: Inserting a page through the [insert dropdown](/docs/copilot/prompt-dialog/placeholders#insert-placeholder-dropdown) adds a separating space when the cursor sits inside a word, so the mention resolves instead of landing as plain text.
