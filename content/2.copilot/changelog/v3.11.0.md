**🚀 Features**

- **Config validation for skills and prompt templates**: With Kirby's `debug` option on, a malformed [`skills`](/docs/copilot/configuration/global#skills) or [`promptTemplates`](/docs/copilot/configuration/global#prompttemplates) entry – and two skills sharing an `id` – now throw instead of failing silently. See the [exceptions reference](/docs/copilot/php-classes/exceptions).

**🐞 Bug Fixes**

- **Failed generations report the failure**: A run that fails now shows the provider's message instead of the success notification, and leaves the incomplete result unsaved.
- **Inline suggestions follow your typing**: Only your own keystrokes start an [inline suggestion](/docs/copilot/usage/inline-suggestions) – text from a generation run, an undo or a redo no longer does. A provider that just failed is left alone for half a minute, and a superseded request stays cancelable.
- **Skills in programmatic prompts**: Skill mentions resolve in every generation run, not just after the prompt dialog has been opened. See the [skills documentation](/docs/copilot/prompt-dialog/skills).
- **Unresolved mentions**: An unknown skill ID or an unreadable [page reference](/docs/copilot/prompt-dialog/page-references) now names itself in a browser console warning instead of vanishing silently.
