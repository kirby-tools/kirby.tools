::tip
This release lets [Agents](/docs/copilot/agents) read what your blueprints tell editors, and keeps an open Panel view from saving over what an agent wrote.
::

**🚀 Features**

- **Blueprint guidance**: Agents now read each field's help, placeholder, and `when` condition, and the text of info fields and info sections, as editors do. House rules you write there guide agents too. See [What Agents Are Told](/docs/copilot/agents/tools#what-agents-are-told).
- **Plugin field types**: A plugin can map its own field type to a core type, and agents and Copilot in the Panel then write it like that field. See [Supported Field Types](/docs/copilot/advanced/reference#supported-field-types).
- **Tools by role**: An agent now sees every tool your role allows, and a tool its connection lacks answers with the permission it needs. When the agent asks for it, the consent view starts from the permissions you gave that agent's last connection.
- **Paused connections**: Admins now see the connections of users whose role may no longer connect agents, marked **Role has no access**, and can revoke them.

**🐞 Bug Fixes**

- **Open Panel views**: Typing in a page you have open no longer saves over what an agent wrote in the meantime. Clicking **Save** or **Discard** after an agent's write reloads the view first, so you see what would go live or be thrown away.
