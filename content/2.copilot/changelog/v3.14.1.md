::tip
This release hardens [Agents](/docs/copilot/agents), Copilot's MCP server that ChatGPT, Claude, and other agents connect to.
::

**🚀 Features**

- **Uploads into drafts**: With Prepare changes, an agent can now upload files to a draft and the pages inside it. The file goes live when you publish the draft. Uploads to published pages and the site still need Publish changes. See [Permissions & Review](/docs/copilot/agents/permissions-and-review#prepare-changes).
- **Asking for a missing permission**: When an agent needs a permission your role allows but its connection lacks, ChatGPT and Claude ask you to connect again, and the consent view marks the permission for you to tick. Other agents tell you to allow it in the Agents view.
- **Every field in view**: Agents now see the fields they can't write, such as a plugin's own field type, as read-only, and leave them to you.

**🐞 Bug Fixes**

- **Safer writes**: Agents can no longer add script links to link and URL fields, inside blocks and structures too.
