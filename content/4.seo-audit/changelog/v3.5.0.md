**🚀 Features**

- **Unsaved changes analyzed**: The analysis now reads what the form shows, not only the published page. The report says which one it looked at – "Unsaved changes" or "Published version" – and when.
- **SEO and readability lights**: The report opens with one light per category, so the verdict comes before the list of checks.
- **Ratings**: Each analysis leaves a [rating](/docs/seo-audit/guide/ratings) per page and language. The view button shows it as a colored dot, with an exclamation mark once the page was published again. Blueprints and templates can read it and sort pages by it.
- **Analyze on publish**: With [`auto: publish`](/docs/seo-audit/configuration/global#auto), the analysis runs on its own after every publish, silently, so the rating keeps up with the content.

**🚨 Breaking Changes**

- **View button theme**: The default is now `positive-icon`, the icon-only accent Kirby uses for the status button. Set `theme: positive` to keep the filled button.
