**🚀 Features**

- **Proxy URL option**: Global `transformers.proxyUrl` option to further modify the request URL of the content fetcher proxy.

**🐞 Bug Fixes**

- **Proxy error handling**: When the proxy fetched a page that answered with an error status, such as `404`, the analysis stopped. It now analyzes the error page and logs a warning to the browser console.
