**🚀 Features**

- **Blueprint-defined keywords**: The new [`keyphrase`](/docs/seo-audit/configuration/local#keyphrase) and [`synonyms`](/docs/seo-audit/configuration/local#synonyms) properties set the keyphrase and synonyms in the blueprint, as an alternative to fields an editor fills in. Both accept **Kirby queries**, so the page title can serve as the keyphrase next to a list of synonyms:

```yaml [sections/seo-audit.yml]
type: seo-audit
keyphrase: "{{ page.title.value }}"
synonyms:
  - Kirby
  - SEO
  - Audit
```
