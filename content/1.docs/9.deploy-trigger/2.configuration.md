## Plugin Options

Both options live under `johannschopplich.deploy-trigger` in `config.php`.

### `deployUrl` :u-badge{label="String" class="align-middle ml-2 rounded-full!" variant="subtle"}

The URL of the deploy hook. Every click sends a `POST` request to it. Required – there is no default.

```php [site/config/config.php]
return [
    'johannschopplich.deploy-trigger' => [
        'deployUrl' => 'https://api.netlify.com/build_hooks/<hook-id>'
    ]
];
```

### `requestOptions` :u-badge{label="Array" class="align-middle ml-2 rounded-full!" variant="subtle"}

Options for Kirby's [`Remote`](https://getkirby.com/docs/reference/objects/http/remote) class. Defaults to `[]`, a `POST` without a body. The ones a deploy hook asks for most:

| Option      | Sets                                                                      |
| ----------- | ------------------------------------------------------------------------- |
| `headers`   | Request headers, such as `Authorization`, as an array of names and values |
| `data`      | The request body – an array is sent as form fields, a string as it is     |
| `agent`     | The `User-Agent` header                                                   |
| `basicAuth` | HTTP basic authentication, as `user:password`                             |
| `method`    | The HTTP method, for a hook that doesn't take `POST`                      |
| `timeout`   | Seconds to wait for the hook's response                                   |

A hook that expects JSON gets the body through `json_encode()` and a matching `Content-Type`:

```php [site/config/config.php]
return [
    'johannschopplich.deploy-trigger' => [
        'deployUrl' => 'https://example.com/hooks/deploy',
        'requestOptions' => [
            'headers' => [
                'Authorization' => 'Bearer <token>',
                'Content-Type' => 'application/json'
            ],
            'data' => json_encode(['branch' => 'main']),
            'timeout' => 30
        ]
    ]
];
```

::callout{icon="i-ri-arrow-right-line" color="info" to="/docs/helpers/environment-variables"}
To keep the token out of version control as well, read it from a `.env` file in `config.php` – see **Environment Variables** in Kirby Helpers.
::
