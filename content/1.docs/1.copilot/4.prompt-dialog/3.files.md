---
title: File Attachments
description: Enrich prompts with visual and document context, including automatic image resizing and native PDF parsing.
---

Kirby Copilot lets you select files to enrich the user prompt with additional information. For example, you can select product images and ask the AI model to describe the product visually, or select PDF files and let the AI model use these documents to generate summaries or extract key information.

## Supported AI Models

::warning
Images and PDF files need an AI model that supports file processing. A model without it ignores the files.
::

## Images

### Resizing

Selected images are downscaled in the browser to fit within 2048 pixels before they are sent to the AI provider.

## Processing PDF Files

The [Select files](/docs/copilot/usage/section#files) button sends selected PDF files directly to the AI provider along with your prompt.

::note
The AI provider sets how large and how long the attached PDFs may be. Your web server's request size limit applies as well, since every request passes through Kirby.
::

## File as Context Source

On a Kirby file page, a Copilot field with [`files: auto`](/docs/copilot/usage/section#files) attaches the current image as context – for alternative text, captions, or descriptions. Only images are attached this way; attach a PDF through the file picker instead, which `files: true` provides.
