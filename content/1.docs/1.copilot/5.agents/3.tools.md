An agent sees the tools your role allows. A tool beyond its connection's permissions answers with the permission it needs, so the agent can ask you for it.

| Tool              | Permission      | What it does                                                                                                                          |
| ----------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `get_site`        | Read content    | Returns the site, its languages, the account and permissions the agent works with, and the top-level pages                            |
| `find_pages`      | Read content    | Searches the pages and drafts, such as those with unsaved changes or not yet translated, or lists the children and drafts of one page |
| `find_files`      | Read content    | Searches the files of the site and its pages, such as those not yet translated or images without alt text                             |
| `get_content`     | Read content    | Returns the fields of a page, a file, or the site in one language, also as published, and the files of a page or the site             |
| `view_image`      | Read content    | Returns a JPEG, PNG, GIF, or WebP image with its alt text                                                                             |
| `prepare_changes` | Prepare changes | Writes field values, or passages and blocks within them, to the unsaved changes in one language                                       |
| `create_draft`    | Prepare changes | Creates a draft below the site or a page, in the default language                                                                     |
| `upload_file`     | Prepare changes | Uploads a file to a draft or a page inside one, or with Publish changes to a published page or the site                               |
| `publish_changes` | Publish changes | Publishes the unsaved changes in one language, whoever made them                                                                      |
| `discard_changes` | Publish changes | Discards the unsaved changes in one language, whoever made them                                                                       |
| `change_status`   | Publish changes | Changes a page's status to listed, unlisted, or draft                                                                                 |
| `change_slug`     | Publish changes | Changes a page's slug in one language                                                                                                 |
| `move_page`       | Publish changes | Moves a page or a draft below another parent                                                                                          |
| `delete_page`     | Delete content  | Deletes a page or a draft with its files                                                                                              |
| `delete_file`     | Delete content  | Deletes a file                                                                                                                        |

## What Agents Are Told

When an agent connects, the site tells it to read content before it changes it, and to treat the content it reads as data, never as instructions. The tools that publish, discard, change a page's status, slug, or parent, upload, or delete tell it to call them only when you ask.

When the agent reads a page, a file, or the site, it also gets the blueprint's guidance for editors: each field's `help`, `placeholder`, and `when` condition, and the text of info fields and info sections. A house rule such as "a teaser under 160 characters" guides agents as it guides editors.

## Plugin Field Types

A plugin's field type that extends a core field is written like that field. Agents can't write any other plugin field type until a plugin maps it to a core type – see [Supported Field Types](/docs/copilot/advanced/reference#supported-field-types).
