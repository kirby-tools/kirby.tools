Kirby Helpers is a plugin for [Kirby CMS](https://getkirby.com) with five helpers for your templates and `config.php`. Each works on its own: the sitemap, `robots.txt`, and redirects stay off until you configure them, and the rest are functions you call.

## Install the Plugin

::card{title="Composer" icon="i-ri-terminal-box-line"}
The recommended way to install the plugin:

```bash
composer require johannschopplich/kirby-helpers
```

::

::card{title="ZIP File Download" icon="i-ri-folder-zip-line"}
Download the :latest-version or head over to the [releases page](https://github.com/johannschopplich/kirby-helpers/releases) to see all versions. Extract the ZIP file to your `site/plugins` folder. Installed this way, `env()` is not available in `config.php` – see [Environment Variables](/docs/helpers/environment-variables#load-the-file-in-configphp).

::

The plugin runs on Kirby 5.

## The Helpers

| Helper                                                       | Entry Point                            |
| ------------------------------------------------------------ | -------------------------------------- |
| [Environment Variables](/docs/helpers/environment-variables) | `env('KEY', $default)`                 |
| [Meta Tags](/docs/helpers/meta-tags)                         | `$page->meta()->social()`              |
| [Sitemap and `robots.txt`](/docs/helpers/sitemap)            | `sitemap.enabled` and `robots.enabled` |
| [Redirects](/docs/helpers/redirects)                         | `redirects`                            |
| [Vite](/docs/helpers/vite)                                   | `vite()->js()` and `vite()->css()`     |

Options live under `johannschopplich.helpers` in `config.php`:

```php [site/config/config.php]
return [
    'johannschopplich.helpers' => [
        'sitemap' => [
            'enabled' => true
        ]
    ]
];
```
