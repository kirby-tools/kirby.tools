## `frontendUrl()`

Returns the page's URL on your frontend, taken from `headless.panel.frontendUrl`, or `null` without that option. `site.frontendUrl()` does the same for the site. Blueprints use both for preview links – see [Panel Configuration](/docs/headless/configuration/panel) for the setup:

```yaml [site/blueprints/pages/default.yml]
options:
  preview: "{{ page.frontendUrl }}"
```

## `breadcrumbMeta()`

Returns breadcrumb navigation data for the current page. Useful for building breadcrumb navigation in your frontend.

### Usage

```ts
import type { KirbyQuerySchema } from "kirby-types";

export const pageQuery: KirbyQuerySchema = {
  query: 'page("blog/article")',
  select: {
    title: true,
    breadcrumbMeta: true,
  },
};
```

### Response

```json
{
  "code": 200,
  "status": "OK",
  "result": {
    "title": "Article Title",
    "breadcrumbMeta": [
      {
        "title": "Blog",
        "uri": "blog"
      },
      {
        "title": "Article Title",
        "uri": "blog/article"
      }
    ]
  }
}
```

## `i18nMeta()`

Returns page metadata for all languages. Essential for building language switchers in multi-language sites.

### Usage

```ts
import type { KirbyQuerySchema } from "kirby-types";

export const pageQuery: KirbyQuerySchema = {
  query: 'page("home")',
  select: {
    title: true,
    i18nMeta: true,
  },
};
```

### Response

```json
{
  "code": 200,
  "status": "OK",
  "result": {
    "title": "Home",
    "i18nMeta": {
      "en": {
        "title": "Home",
        "uri": "home"
      },
      "de": {
        "title": "Startseite",
        "uri": "home"
      }
    }
  }
}
```
