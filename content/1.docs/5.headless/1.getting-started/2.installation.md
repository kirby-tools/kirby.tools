## Install the Plugin

::card{title="Composer" icon="i-ri-terminal-box-line"}
The recommended way to install the plugin:

```bash
composer require johannschopplich/kirby-headless
```

::

::card{title="ZIP File Download" icon="i-ri-folder-zip-line"}
Download the :latest-version or head over to the [releases page](https://github.com/johannschopplich/kirby-headless/releases) to see all versions. Extract the ZIP file to your `site/plugins` folder.

::

The `/api/kql` endpoint needs Kirby's official KQL plugin: `composer require getkirby/kql`.

## Default Behavior

The plugin works out of the box without additional configuration. By default:

- KQL endpoint available at `/api/kql`, protected by Kirby's native API authentication ([bearer token auth](/docs/headless/configuration/authentication) is opt-in)
- Sitemap endpoint at `/api/__sitemap__` and template endpoint at `/api/__template__/<name>`, both public until you set a [`headless.token`](/docs/headless/configuration/authentication#what-the-token-protects)
- Existing routes and templates remain unaffected until you enable [global routes](/docs/headless/usage/json-templates#global-routes)

Configure bearer token or basic auth under [Authentication](/docs/headless/configuration/authentication), cross-origin requests under [CORS](/docs/headless/configuration/cors), and preview URLs and redirects under [Panel](/docs/headless/configuration/panel).
