## Step 1: Install the Plugin

Although it is a commercial plugin, you can download and test it in your local environment before purchasing.

::card{title="Composer" icon="i-ri-terminal-box-line"}
The recommended way to install the plugin:

```bash
composer require johannschopplich/kirby-seo-audit
```

::

::card{title="ZIP File Download" icon="i-ri-folder-zip-line"}
Download the :latest-version or head over to the [releases page](https://github.com/kirby-tools/kirby-seo-audit/releases) to see all versions. Extract the ZIP file to your `site/plugins` folder.

::

## Step 2: Choose Your Workflow

Kirby SEO Audit offers two ways to add SEO analysis to the Panel. Both run the same analysis, share their configuration, and can be used together – the field additionally remembers its last report through `persisted`.

::card-group

:::card{title="View Button" icon="i-ri-layout-top-line" to="/docs/seo-audit/configuration/local#view-button-configuration"}

Add the SEO Audit view button to the Panel **header** – it opens the report in a dialog.

```yaml [pages/default.yml]
buttons:
  - seo-audit # Choose position
  - open # `buttons` replaces Kirby's
  - preview # defaults, so list them all
  - "-"
  - settings
  - languages
  - status
```

:::

:::card{title="Field" icon="i-ri-dashboard-line" to="/docs/seo-audit/configuration/local#field-configuration"}

Alternative display with analysis results inline within the page content.

```yaml [pages/default.yml]
fields:
  seoAudit:
    type: seo-audit
```

:::

::

## Step 3: Configure Keyphrase Fields (Optional)

SEO assessments that analyze how the keyphrase is used, such as Introduction Keyword, Meta Description Keyword, or Function Words, need a defined keyphrase – see [`keyphraseField`](/docs/seo-audit/configuration/local#keyphrasefield) for what happens without one. You can define blueprint fields for the keyphrase and its synonyms to be analyzed with your page. These fields can be used by both the view button and the SEO Audit field:

::code-collapse

```yaml [pages/default.yml]
# Configure the view button to use keyphrase fields
buttons:
  seo-audit:
    keyphraseField: metaKeyphrase
    synonymsField: metaSynonyms
  open: true
  preview: true
  settings: true
  languages: true
  status: true

fields:
  # Define the keyphrase fields
  metaKeyphrase:
    label: SEO Keyphrase
    type: text
    help: The keyphrase you want this page to rank for
  metaSynonyms:
    label: Keyphrase Synonyms
    type: tags
    help: Synonyms and variations of the keyphrase

  # Configure the field to use the same fields
  seoAudit:
    type: seo-audit
    keyphraseField: metaKeyphrase
    synonymsField: metaSynonyms
```

::

::callout{icon="i-ri-information-line" color="info" to="/docs/seo-audit/configuration/local"}
Every property of the view button and field – assessments, content selector, links – is listed in the configuration guide.
::

## Step 4: Analyze Your Content

Open the Panel and navigate to the page that you want to analyze. You can start the analysis in two ways:

- **Using the View Button**: Click the **SEO Audit** button and the analysis results will open in a dialog.
- **Using the Field**: Click the **Analyze** button in the field. The results will be displayed directly in the field.

The analysis reads the page behind its [preview URL](/docs/seo-audit/guide/preview-url), unsaved changes included.

Enter the email you used for the purchase and your license key, then hit the submit button. You will find your license key in your order confirmation email or at [hub.kirby.tools](https://hub.kirby.tools). Done! Thanks for supporting my work. Once you activate your license, the license activation buttons will disappear.

::note
Your license key will be stored automatically in `/site/config/.kirby-tools-licenses`. This file is created on first activation. Make sure to add it to your `.gitignore` to keep your license key private.
