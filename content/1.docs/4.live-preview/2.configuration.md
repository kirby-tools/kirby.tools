## Field Properties

### `label` :u-badge{label="String" class="align-middle ml-2 rounded-full!" variant="subtle"}

The `label` property defines a custom label for the Live Preview field. The default value depends on the Panel language. For English, the default label is `Live Preview`.

To set a custom label, use the `label` property in your blueprint:

```yaml [fields/live-preview.yml]
type: preview
label: Real-Time Preview
```

### `pageId` :u-badge{label="String" class="align-middle ml-2 rounded-full!" variant="subtle"}

By default, the Live Preview field displays the current page being edited in the Panel (or the home page if it is being rendered at site level). Set `pageId` to preview another page by its ID:

```yaml [fields/live-preview.yml]
type: preview
pageId: about
```

On the site blueprint, that page shows the site's unsaved changes. On a page blueprint, another page renders as saved.

### `updateInterval` :u-badge{label="Number | false" class="align-middle ml-2 rounded-full!" variant="subtle"}

Defaults to 500 milliseconds – how long the editor pauses typing before unsaved changes rerender the preview. Anything under 250 is lifted to 250. A negative integer or any value other than an integer or `false` shows an error in place of the field.

To wait longer for a pause, use the `updateInterval` property:

```yaml [fields/live-preview.yml]
type: preview
updateInterval: 1000
```

To stop the preview from following your typing, set the `updateInterval` property to `false`:

```yaml [fields/live-preview.yml]
type: preview
updateInterval: false
```

The preview still renders:

- when the field loads
- when the page title changes
- when files are sorted
- when the Panel language switches
- when an editor clicks **Refresh preview**

### `interactable` :u-badge{label="Boolean" class="align-middle ml-2 rounded-full!" variant="subtle"}

Enabled by default – editors can click links and buttons inside the preview. Set it to `false` or `0` to make the preview inert – the page gets `pointer-events: none`, so clicks and hovers no longer reach it. A site rule that sets `pointer-events` with `!important` wins over it.

```yaml [fields/live-preview.yml]
type: preview
interactable: false
```

### `aspectRatio` :u-badge{label="String" class="align-middle ml-2 rounded-full!" variant="subtle"}

The Live Preview field grows to fit the height of the Panel window. Set `aspectRatio` to give the preview area a fixed ratio instead.

The aspect ratio value must be a string formatted as `width/height` (e.g., `16/9`). Any other string, `16:9` included, shows an error in place of the field.

```yaml [fields/live-preview.yml]
type: preview
aspectRatio: 16/9
```

### `help` :u-badge{label="String" class="align-middle ml-2 rounded-full!" variant="subtle"}

Like other Kirby fields, the Live Preview field takes a help text. The text is displayed below the preview window and supports Kirbytext formatting.

```yaml [fields/live-preview.yml]
type: preview
help: |
  Shows the page with your unsaved changes as you type.
```
