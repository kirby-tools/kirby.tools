**🚀 Features**

- **Slug translation API**: New [`translateSlug`](/docs/content-translator/php-classes/translator#translateslug) PHP API method.
- **Batch translation mode**: [Batch translation mode](/docs/content-translator/configuration/local#batch) overwrites the content of all secondary languages with the data of the default language and then translates into the respective language.

Unlike per-language translation, a batch run **is not reversible** in the Panel and may take a while, so a confirmation dialog asks first.

::note
If this new feature breaks your workflow, you can disable it by setting `batch: false` in the plugin configuration.
::

**🐞 Bug Fixes**

- **Home page translation skips the slug**: Translating the home page with `slug` enabled ended in an error, since Kirby does not let the home page's slug change. The slug is now skipped.
