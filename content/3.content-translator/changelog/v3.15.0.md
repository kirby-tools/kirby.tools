::tip
A translation run now reports what it left behind. When a segment keeps its source text, the run says which field it was and why – in the Panel, in the console, and as a return value for [`translateContent()`](/docs/content-translator/php-classes/translator#translatecontent).
::

**🚀 Features**

- **Batch runs name the language that went wrong**: Translating into several languages at once used to sum everything into one count, which hid a language that failed entirely. The notification now names each language that kept source text.
- **A dropped link is named, not counted**: When a translation loses or duplicates a KirbyTag link, the console says which links it expected and which came back. See [Translation Results](/docs/content-translator/panel/translation-results).
- **`translateContent()` returns a result**: Instead of `void`, you get `translatableCount`, `translatedCount` and one rejection per dropped segment, each naming its field and reason. See [Translator](/docs/content-translator/php-classes/translator#translatecontent).
- **A custom strategy can report a single failed segment**: Returning `null` for a slot keeps that segment's source text and records it as a drop, instead of failing the whole batch. See [Strategies](/docs/content-translator/php-classes/strategies#implementing-a-custom-strategy).

**🐞 Bug Fixes**

- **A failed title no longer overwrites a translated one**: A rejected title or slug translation used to write the source-language text into the target language, silently replacing a title you had translated by hand. It now leaves both untouched.
- **AI drops are visible again**: A segment the AI provider dropped was written back as source text and counted as translated. It is now reported as a drop.
- **DeepL stops mangling text around KirbyTag links**: A paragraph whose only markup was a KirbyTag link came back with escaped characters (`s&#x27;ouvre`) and shifted spacing. A [`tag_handling` you configured yourself](/docs/content-translator/php-classes/deepl-client) is respected unchanged.
- **A drop is reported once**: A segment a custom strategy dropped fired the [warning hook](/docs/content-translator/advanced/hooks#content-translatortranslatewarning) twice.
