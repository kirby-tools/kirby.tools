::tip
A translation run now hands back what it did. `translateContent()` returns counts plus one rejection per segment that kept its source text, each naming its field and reason – no hook wiring needed to notice a drop. See the [migration guide](/docs/content-translator/getting-started/migration#migrating-to-v315-rejection-results).
::

**🚀 Features**

- **`translateContent()` returns a result**: Instead of `void`, you get `translatableCount`, `translatedCount` and a rejection per dropped segment. See [Translator](/docs/content-translator/php-classes/translator#translatecontent).
- **Batch runs name the language that went wrong**: Translating into several languages at once used to sum everything into one count, which hid a language that failed entirely. The notification now names each language that kept source text.
- **Console names the placeholders that broke**: A `placeholder mismatch` now reports which `<cN/>` links were expected and which came back, instead of only the count.
- **`null` marks a unit a custom strategy could not translate**: The [strategy contract](/docs/content-translator/php-classes/strategies#implementing-a-custom-strategy) takes `null` for a failed slot, so the segment keeps its source text and shows up as a drop.

**🐞 Bug Fixes**

- **A failed title no longer overwrites a translated one**: A rejected title or slug translation used to write the source-language text into the target language, silently replacing a title you had translated by hand. It now leaves both untouched.
- **AI drops are visible again**: A segment the AI provider dropped was written back as source text and counted as translated. It is now reported as a drop.
- **DeepL keeps text around KirbyTag links intact**: Text whose only markup is a `<cN/>` link placeholder went out with HTML tag handling, which entity-escaped the surrounding prose (`s&#x27;ouvre`) and shifted whitespace around the link. A `tag_handling` you configured yourself is respected unchanged.
- **One drop is reported once**: A unit a custom strategy dropped fired the warning hook twice, the second time under a guessed reason.
