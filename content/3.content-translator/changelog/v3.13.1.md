**🐞 Bug Fixes**

- **Plain text keeps its special characters**: Text and tags fields, code blocks, and Markdown no longer come back with `&#x27;`, `&lt;` and `&gt;` where the source had `'`, `<` and `>`. DeepL's HTML tag handling is now sent only for text that actually carries markup, such as Writer fields and blocks. Content translated before this version keeps its escaped characters and needs a re-translation. See the [documentation](/docs/content-translator/php-classes/deepl-client#request-options).
