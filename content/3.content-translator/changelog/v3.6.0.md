**🚀 Features**

- **Kirby Table plugin support**: Added translation support for the [Kirby Table plugin](https://github.com/bogdancondorachi/kirby-table-field) by Bogdan Condorachi. Table cell content is now properly translated in both Panel (client-side) and programmatic (server-side) translation modes.

**🐞 Bug Fixes**

- **Batch translation works for files**: A batch translation started from a file failed with an error. The file's metadata now translates.
