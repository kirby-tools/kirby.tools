**🚀 Features**

- **Full DeepL language catalogue**: Languages such as Catalan, Serbian, Swahili, Cantonese, and Welsh now translate instead of failing with an unsupported-language error. See the [DeepL documentation](/docs/content-translator/providers/deepl#supported-languages).
- **Language code overrides**: The new `targetLanguageOverrides` config option maps a Kirby language code to any DeepL target code – including codes DeepL releases after this version. See the [DeepL documentation](/docs/content-translator/providers/deepl#language-code-overrides).

**🐞 Bug Fixes**

- **Regional variants follow the language code**: A `de-ch` language now translates to Swiss German and `zh-tw` to Traditional Chinese, even when the server locale disagrees. Previously the locale won, so sites with both a Simplified and a Traditional language received identical translations for the two. Thanks to [@gutschik](https://github.com/gutschik) for the report.
