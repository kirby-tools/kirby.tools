The [Kirby Tools Plugin License Agreement](https://kirby.tools/license) ("main agreement") applies to the Kirby Tools plugins distributed in the Zero One Theme package ("Plugins"), with the following changes. This addendum covers Theme Licenses bought on or after its last update, together with the main agreement as in effect when the Theme License was bought. Earlier Theme Licenses stay under the Zero One Edition terms in effect when they were bought.

## 1. Definitions

- **Theme Seller** means The Zero (thezero.club).
- **Zero One Theme** means the Theme Seller's Zero One theme for Kirby CMS.
- **Theme License** means the Theme Seller's license for the Zero One Theme.
- **Valid Theme License** means a Theme License that was lawfully obtained, has not been refunded in full or charged back in the buyer's favor, and under its terms covers the End Product. A time-limited Theme License counts only as long as its terms allow running the End Product.
- **End Product** means a Kirby site built with the Zero One Theme, including modified versions.
- **Licensee** or **you** means whoever lawfully obtained the Zero One Theme package.

The Zero One Edition currently includes Kirby SEO Audit.

## 2. License Grant

In the main agreement's section "License Grant", End Products covered by a Valid Theme License that you or your Client hold take the place of Projects you are the Code Owner of. The number of End Products follows the Theme License.

You may deliver an End Product to a Client. The Client may run the End Product but may not extract or reuse the Plugins.

## 3. No License Key

The Plugins run without a license key or activation. That does not widen the permitted use. You may not circumvent the check that limits the Plugins to the Zero One Theme.

## 4. Updates and Purchase

Updates to the Plugins come only with updates to the Zero One Theme. Payment, invoices, refunds, and downloads go through the Theme Seller.

## 5. Loss of the Theme License

Losing the Valid Theme License for an End Product ends your right to use the Plugins in it.

## 6. Sections That Do Not Apply

The main agreement's sections "Purchase and Refunds", "Versions and Updates", "Client Projects", "License Keys", and "Transfer" do not apply.

## 7. Distribution by the Theme Seller

Only the Theme Seller distributes the Plugins, and only inside the Zero One Theme package.
