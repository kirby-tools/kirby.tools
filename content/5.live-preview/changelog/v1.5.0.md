**🚀 Features**

- **Update strategy option**: The new [`updateStrategy`](/docs/live-preview/configuration#updatestrategy) property controls when the preview updates. Set it to `blur` instead of the default `interval` to update the preview when a text-like, number-like, or blocks field loses focus:

```yaml [sections/live-preview.yml]
type: preview
updateStrategy: blur
```
