# Kirby Tools

The website, documentation and agent-facing surface for a set of Kirby CMS plugins. Its terms are defined in `CONTEXT.md`, use them by name.

- `layers/kirby-panel/kirby` is a checkout of Kirby's source, and Kirby's license forbids redistributing it. The mocks reach it at runtime; anything copied out of it stays out of git.
- The plugin repositories sit next to this one as `../kirby-<ProductId>`.
